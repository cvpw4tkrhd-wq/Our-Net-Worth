# Privat budget

Personlig utgiftsapp (PWA). Importera egna utgifter från bankfil eller inklistrad text, få dem kategoriserade och jämför månad för månad. Hälften av hushållets gemensamma utgifter skrivs in för hand.

- All data ligger i webbläsaren (localStorage + IndexedDB). Inget skickas någonstans, utom till din egen Gist om du slår på den.
- Lägg aldrig riktiga kontoutdrag eller backupfiler i det här repot.
- Version: se `APP_VERSION` i `index.html`. Höj samma nummer i `sw.js` vid varje ny version.
