# Our Net Worth

Vad vi har sparat nu och vad vi kan ha om några år. Saldon matas in manuellt varje månad, för två personer och gemensamt (kontantinsats, amortering och värdeökning på bostaden). Prognosen räknar år för år.

- All data ligger i webbläsaren (localStorage + IndexedDB). Inget skickas någonstans, utom till din egen Gist om du slår på den.
- Repot är publikt. Lägg aldrig backupfiler med riktiga saldon här.
- Version: se `APP_VERSION` i `index.html`. Höj samma nummer i `sw.js` vid varje ny version.
